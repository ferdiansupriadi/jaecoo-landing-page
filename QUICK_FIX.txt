# 🚨 QUICK DIAGNOSTIC - ERROR 500 

## Kemungkinan Penyebab (Urutan Likelihood)

### 1. ⚠️ .htaccess Issues (80% kemungkinan)
- Rewrite rules conflict
- mod_rewrite tidak aktif
- FilesMatch syntax error
- Header directives tidak didukung

**Fix:** Upload .htaccess.minimal atau .htaccess simplified

---

### 2. ⚠️ Script Errors (15% kemungkinan)
- config.js loading error
- scripts-index.js syntax error
- Missing closing tag

**Fix:** Check browser console (F12), check script syntax

---

### 3. ⚠️ PHP Issues (5% kemungkinan)
- Backend folder/php file issues
- PHP version incompatibility

**Fix:** Don't upload backend unless necessary

---

## IMMEDIATE ACTION

### Step 1: Cek Error Log (PENTING!)
```bash
# Via SSH:
tail -100 /var/log/apache2/error.log
# Atau
tail -100 /var/log/httpd/error.log
```
Catat exact error message!

---

### Step 2: Test Without .htaccess
```bash
# Rename .htaccess temporarily
mv .htaccess .htaccess.backup
# Test: curl https://yourdomain.com/j7.html
```

Jika error hilang = .htaccess masalahnya
Jika masih error = Script atau PHP masalahnya

---

### Step 3: Replace .htaccess
Ada 3 pilihan:
1. `.htaccess` (current simplified)
2. `.htaccess.minimal` (ultra-minimal)
3. Copy paste original yang sudah working

---
